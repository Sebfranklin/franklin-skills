# Franklin's Agent Skills

A collection of Agent Skills for Gemini CLI, OpenCode, and other AI agents, following the [agentskills.io](https://agentskills.io) specification.

## Installation

To install these skills globally for all supported agents:

```bash
npx skills add Sebfranklin/franklin-skills --all -g
```

## Available Skills

This repository contains skills for:
- **Development**: Python, JS, Playwright, Testing, Git Workflows, Next.js Turbopack.
- **Cloud & Infrastructure**: Cloudflare, Supabase, API Management.
- **Content Creation**: Image-to-Video, Video Studio, HyperFrames, GSAP Animations, CSS Animations.
- **Design & Art**: Algorithmic Art, Canvas Design, Theme Factory.
- **Productivity**: Obsidian, GWS Docs, Document Creation, PDF/PPTX/XLSX/Docx processing.
- **Advanced Automation**: MemPalace Cognition, Trixel Hermes, CI/CD, Project Architecture.
- And more.
